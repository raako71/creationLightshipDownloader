# Creation Lightship Downloader

Scripts and a PWA for browsing and downloading mp3s from the [Creation Lightship Archive](https://creationlightship-archive.com).

## PWA

A progressive web app that shows archive recordings for **yesterday** and **today** in a two-column layout. Year links open the corresponding mp3 directly.

🔗 **[https://raako71.github.io/creationLightshipDownloader/](https://raako71.github.io/creationLightshipDownloader/)**

## Scripts

- **`Downloader.py`** – command-line tool to search the archive by date and download mp3 files.
- **`setTags.py`** – updates ID3 tags and renames downloaded mp3 files.
